# Gulzaar

A luxury wedding invitation landing page built with React and Vite. This project presents a royal, cinematic event experience with a rich visual style, event details, timeline, and RSVP section.

## Features

- Elegant wedding invitation design
- Responsive layout for mobile and desktop
- Event schedule, details, and story sections
- RSVP CTA section
- Ready for deployment with Cloudflare Pages and Wrangler

## Tech Stack

- React
- Vite
- Cloudflare Pages

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

```bash
npm run deploy
```

This project is configured for Cloudflare Pages deployment via Wrangler.
